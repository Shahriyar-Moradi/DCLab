How autonomy grows

Each decision point earns its trust level with evidence

A decision point starts at L0. It moves up one level only when the R3 evaluation shows the AI is at least as good as the rule it replaces, on labeled cases, within cost and latency budgets. Moving a point up or down is itself a decision record.

L0 · Shadow

AI answers, the answer is logged next to the rule's answer. Nothing changes for the user.

Where everything starts. Builds the labeled corpus.

L1 · Advise

AI answer shown with its evidence. A person accepts or rejects it.

Spec, split strategy, column exclusion, promotion.

L2 · Auto + revert

Applied automatically when the validator agrees. One-click revert in the inbox.

Column roles, model families, next improve iteration.

L3 · Auto + notify

Agent acts within a workspace policy. Person is notified and can roll back.

Retrain on drift, rollback when a release underperforms.

AI-first architecture

Agents act through the same tools as MCP; the tools are the safety boundary

The lead agent runs multi-step tool loops. Because every tool validates its input and only deterministic services change state, agents can be given more freedom than one-call proposals without being able to skip a split rule or read the holdout.

The user states a goal; the lead agent runs the project

Forms still exist as a fallback, but the main surface is a conversation plus a decision inbox. Every decision the agent makes shows its trust level, and L1 decisions wait for a click.

Risks of going AI-first

What gets harder

  • LLM spend becomes the largest running cost, larger than training compute. Budgets, caching and model choice per agent are required from day one (see the comparison page).
  • Young dependencies on the critical path. NOOA is alpha with weekly breaking changes; Jev launched two weeks ago with no SLA. Both stay behind adapters with rule fallbacks.
  • Selection leakage from many agent iterations. Needs iteration budgets and the feature-engineering leakage contract before agents propose features.
  • Studio arrives about 3–4 weeks later, and hosted beta about 2 weeks later than in the current plan.
  • Evaluation work moves to the front. Without the R3 harness early, nobody can tell whether the AI helps.
