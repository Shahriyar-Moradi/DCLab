AI review

One thing to confirm

The model is sound and clearly beats the baseline. Most of its signal comes from last_login_days. If that value is only known after a customer has left, real results will be weaker than the test shows.

Is last_login_days known on the day you predict?

Reproduce this run

Plain scikit-learn. Running it on the same data gives the same validation scores.

# Run E1 · churn in the next 30 days · left out: churned_at, customer_id
prep = ColumnTransformer([
    ("numbers",    Pipeline([("fill", SimpleImputer(strategy="median")), ("scale", StandardScaler())]), NUMBERS),
    ("categories", Pipeline([("fill", SimpleImputer(strategy="most_frequent")),
                             ("encode", OneHotEncoder(handle_unknown="ignore"))]), CATEGORIES),
    ("dates",      DateParts(["month", "weekday"]), ["signup_date"]),
])
model = Pipeline([("prep", prep), ("clf", LGBMClassifier(**TUNED, random_state=42))])

# Same folds as the run; the test months are never used here
for train, valid in folds:
    model.fit(X.iloc[train], y.iloc[train])
    score(model, X.iloc[valid], y.iloc[valid])

THRESHOLD = 0.31   # catches at least 80% of churners on validation data
