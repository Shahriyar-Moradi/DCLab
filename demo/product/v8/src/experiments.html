Try a change starts a new run from a finished one; the original is never changed

The new run keeps the parent’s test design, so the two are scored on the same folds. Several changes can go in one run. There is no feature engineering: a column can be left out, kept, filled or split into date parts, but no new column is made. A run can also start from a trust check’s “Try this change”.
