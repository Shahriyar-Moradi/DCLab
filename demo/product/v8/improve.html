Improve

Two ways to look for a better model: an improvement loop within a budget, whose tries never look at the final test set, or one change you try yourself. Keeping the current model is a normal result.

Working today
The loop cannot start on Northwind churn. This test design is ordered by time, and the loop’s comparison rule needs folds that are not ordered in time. Use Try one change yourself here. Below: how a loop works, and a real one on another project in this workspace.

Test design
The starting run’s own: the same folds and the same final test set. A loop on a fresh split is not available yet.

What happens

  1. First a threshold step: can the current model meet the goal at another threshold? Nothing is retrained.
  2. Then each try adds one model family the run has not trained yet, chosen by a fixed rule table. Each try is a sealed run on the same folds: judged on cross-validation only, final test not used.
  3. Each try gets a verdict from its fold-by-fold differences: beats noise within noise worse or not comparable with the reason.
  4. It stops on the budget, the patience, or when nothing is left to try.
  5. A person accepts one try that beat the noise: it is re-run once with its choices pinned, and the final test set is scored once. That one number is shown. Or the person keeps the current model, and the final test set is not used.

Most tries end within the noise, and most loops end with the current model kept. That is the correct answer, not a failure: five folds can only show large gains. Suggestions from the assistant are not built; the rule table always proposes.

Accept a try or keep the current model

Only a signed-in person can accept; an access token or a connected tool cannot. Only a try a person accepts is re-run (retried at most twice if a re-run stops before the final test); the final test set is scored once. Nobody deciding within 14 days keeps the current model.

Every try started here is scored on the final test set once. Do not pick a model by its final-test number. This page never starts a try by itself.
