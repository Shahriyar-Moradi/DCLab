Connect

Use DCLab from your own code, from a terminal, or from a coding assistant such as Claude Code or Cursor.

Python

from dclab_client import DCLabClient

with DCLabClient("https://dclab.example/api/backend", token="dclab_st_...") as api:
    project = api.projects.create(name="Churn")
    upload = api.datasets.upload(project.id, "customers.csv")
    run = api.experiments.create(project_id=project.id, dataset_id=upload.id, target_column="churned_next_30d")
    for check in api.experiments.findings(run.id).checks:   # once the run is completed
        print(check.check, check.status, check.message)
    print(api.model_versions.card("<model version id>").markdown)
    rows = api.datasets.upload(project.id, "new_customers.csv", purpose="scoring")
    pred = api.predictions.create(model_version_id="<model version id>", dataset_id=rows.id)
    if api.predictions.get(pred.id).status == "completed":
        api.predictions.download(pred.id, to="predictions.csv")

dclab.example is a placeholder host: use your own DCLab address. Scoring runs in the background, so check the status before downloading.

Terminal

dclab-cli login --api-url https://dclab.example/api/backend --workspace <id>
dclab-cli data upload customers.csv --project <id>
dclab-cli experiments run --project P --dataset D --target churned_next_30d
dclab-cli experiments findings <run id>
dclab-cli models card <model id>
dclab-cli predict create --model-version MV --dataset D --wait

The command is dclab-cli. Add --json to any command for machine-readable output. dclab.example is a placeholder host.

Tools that read are on by default. Tools that change things are listed only when you also set DCLAB_MCP_WRITE_ENABLED=1. A token can only propose decisions; a person accepts them in DCLab. dclab.example is a placeholder host.
