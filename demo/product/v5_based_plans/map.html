Walk the productRole chooser

An ML lab your AI agent can drive, which proves every model is correct.

For data scientists and ML engineers on tabular data. The unit of work is the versioned ML state graph, not code: datasets, features, splits, models and experiments are typed, versioned nodes. DCLab executes every change as a reproducible experiment, verifies it scientifically, and remembers why each decision was made.

Five differentiators

  1. The state graph with staleness and branching (Phase 2, done).
  2. Verify: automatic scientific investigation, five core checks now, twelve or more in Phase 5.
  3. Improve: a bounded, constraint-driven experiment loop where every iteration is an auditable node (Phase 5).
  4. Project memory as immutable decision records (Phase 2, done).
  5. An R&D benchmark that proves engine quality publicly (R1 done, R1-P in Phase 5).

Interfaces, in delivery order

/v1 API → Python SDK and CLI → MCP server (Claude Code, Cursor, Codex drive DCLab) → Studio with the in-app assistant (same tool catalog as MCP: read tools run, write tools become confirm cards) → internal agents (NOOA proposal classes) → notebook and IDE plugin (later).

Not in the MVP

Online serving, autonomous retraining, arbitrary connectors, stateful Jupyter, dual-cloud parity, external GPU marketplace, SLM fine-tuning, a business decision layer. Each has a place in Phase 9 behind a trigger and an ADR.

The hybrid AI model

AI-first in how users work, deterministic in how results are produced · ADR 0008, ADR 0009
  1. AI proposes at every decision point: target, column roles, leakage suspects, split strategy, families and budget, next improve action, retrain, release, rollback.
  2. Deterministic code validates every proposal: columns exist, actions on an allowlist, the final holdout untouched, the budget not exceeded.
  3. Every decision is a project_decision_records row: who decided (rule, agent, Jev, human), why, cited evidence, the rule's answer, how to revert.
  4. Autonomy is per decision point and earned with evidence (R3): a level changes only when the AI is at least as good as the rule, and the change is itself a decision record.
  5. AI sits before or after each deterministic step, never inside it: AI-before proposes inputs, AI-after reviews outputs (Critic on every run), cross-check runs both.
  6. Jev is used deterministically: pinned release, calibrated thresholds in code, answers cached by input digest, fixed agreement policy.
  7. Specialists make one structured LLM call (NOOA Predict); only the lead agent, which is the in-app assistant, runs bounded tool loops over the same catalog as MCP.
  8. Never AI: model training, metric calculation, final model selection on validation data, holdout scoring, the splits themselves.
  9. Every path works with AI off; disabling NOOA and Jev leaves every test green. Try the AI on switch in the top bar.
L0ShadowAI answers and is logged; the rule decides. Every point starts here.
L1AdviseAI answer shown with evidence; a person accepts. Highest level ever for target, exclusions, leakage flags, split, experiment review, release, rollback and every lead-agent write tool.
L2Auto + revertApplied when the validator accepts it; one-click revert. Numeric ↔ categorical roles, impute choice, families and budget, retrain.
L3Auto + notifyActs under a workspace policy; person notified. ops.diagnose only. Never inside auto-train.

Promotion needs sealed benchmark partitions and blind labels (ADR 0008 §4): L0 → L1 needs ≥ 100 sealed and ≥ 30 blind cases with precision lower bound ≥ 0.90; L1 → L2 needs ≥ 20 datasets, ≥ 300 cases, non-inferiority to the rule and a Wilson lower bound ≥ 0.98 on in-band overrides. Demotion is automatic on evidence of harm, incidents or drift.

  • Holdout plan first (stratified, random, group-disjoint, temporal-future); profile, leakage audit and plans on the locked train partition only.
  • Fit-dependent preprocessing inside per-fold Pipelines; name or correlation alone never excludes a feature.
  • CV-only winner lock, then a single winner-only holdout evaluation; a dummy baseline in every portfolio.
