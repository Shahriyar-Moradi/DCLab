The hybrid model

AI and rules cover each other

1 · Tools are the safety boundary

The lead agent and specialists use the same tools as the MCP server. Each tool checks the request in code, so an agent can't skip the time split or read the test data. That is what makes multi-step agent loops safe.

2 · The state graph is the memory

Datasets, splits, experiments, models and decisions are nodes. The agent reads the graph to know what was tried, what worked and what is stale, not its chat history.

3 · Jev for small typed judgments

"Is this an ID?", "a date?", "might this leak?", "what does the user mean?" in about 100 ms, under a fixed deterministic policy. LLM agents do the reasoning and planning.

4 · Every AI action is a proposal with evidence

A decision record holds what was decided, by whom, why, the cited numbers, the rule's answer and how to undo it. Low-risk decisions apply automatically and reversibly.

5 · Trust levels per decision point

Every point starts at L0. It moves to L1, L2 or L3 only when R3 shows the AI is at least as good as the rule, and the change is itself a decision record.

Specialists vs lead agent

Specialist agents make one structured LLM call and return one typed proposal. The lead agent runs a bounded multi-step tool loop only when the task needs it.

Three layers above the agents

Governance sets the rules, the gateway enforces them on every model call, the harness wraps every agent run

Governance is data per workspace, not a code path. The gateway is the only door to any model; the harness is the only way to run an agent. CI rules keep both true, and every recorded run can be replayed offline.

Where AI sits

AI before or after each important step, never inside it

AI-before proposes inputs and is cross-checked against the rule. AI-after reviews outputs and cites evidence. Training, selection and holdout scoring stay code only.

Jev at each decision point

A model answer, used through fixed code

Jev's answer is one input to a deterministic policy: a pinned release, thresholds owned in code, answers cached by input digest so the same input always gives the same result, and a fixed agreement table.

Stays deterministic

Never AI, and always works with AI off

  • Model training, metric calculation, final model selection on validation data, holdout scoring and the splits themselves are plain code.
  • Column exclusion never goes above L1; Jev is never asked numeric questions; no raw rows go to an LLM without a workspace flag.
  • Turning off NOOA and Jev leaves every Phase 1–5 test green; LLM outages and budget limits fall back to the rule answer.
  • Agents propose features only after the feature-engineering leakage contract (P5.0) is in place.
  • No model call outside the gateway, no agent run outside the harness; both are CI rules, and every recorded run replays offline.
